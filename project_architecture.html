VERIFIED IN SOURCE

Start here: the question path

The main app is app.py. It gets one cached backend.KnowledgeBase, passes questions to kb.answer(), and renders the returned answer, status, and sources. backend.search() prepares a query, combines semantic and BM25 rankings, reranks candidates, and backend.answer() calls Ollama only if the best relevance meets the threshold.
